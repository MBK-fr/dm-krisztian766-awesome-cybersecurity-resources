# Contributing

Thanks for wanting to improve this list! A few simple guidelines:

1. **Relevance** – the resource should be genuinely useful for OSINT, pentesting, malware analysis, forensics, privacy, or general IT security.
2. **Quality** – prefer actively maintained tools/sites over abandoned ones.
3. **Format** – add entries as `[Name](URL) – short description.` under the correct section, keeping alphabetical or logical order within the section.
4. **One resource per line** – keep pull requests focused; large unrelated batches are harder to review.
5. **No self-promotion spam** – linking to your own project is fine if it's genuinely relevant and useful to the list's audience. It is **not** fine if you're opening the same or near-identical PR across many unrelated "awesome" lists at once — that pattern gets closed on sight regardless of how good the tool is, since it signals a link-building campaign rather than a genuine contribution to this list.
6. **New/anonymous domains** – if your project's domain was registered very recently and/or has no identifiable owner (WHOIS privacy is fine, but zero online presence otherwise is a red flag), expect extra scrutiny or a request to wait until it has some track record.

To submit a change:

1. Fork the repository.
2. Create a branch for your change.
3. Add your entry to `README.md`.
4. Open a Pull Request describing the resource and why it belongs here.

Found a broken or outdated link? Open an Issue or submit a PR removing/fixing it.
